# Salah Pakistan

Prayer times for 60+ cities across Pakistan, powered by the Aladhan API.
Built with HTML, CSS, Tailwind (CDN) and vanilla JavaScript. No build step.

## Features
- City picker grouped by province, plus "Use my location"
- Live countdown to the next prayer
- Today's times, monthly timetable, and a table of all cities
- Hanafi / Shafi Asr option, 12 or 24-hour clock

## Run locally
Open `index.html` in a browser, or run `npx serve .`

## Deploy on Vercel
1. Push this folder to a GitHub repository.
2. On vercel.com choose Add New > Project and import the repository.
3. Framework Preset: Other. Leave build command and output directory empty.
4. Click Deploy.

CLI option: `npm i -g vercel`, then `vercel --prod` inside this folder.
